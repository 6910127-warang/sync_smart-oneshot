# SmartSync

ระบบสนับสนุนการเบิกยา SmartSync เครือข่าย รพ.สต. อำเภอเมือง จังหวัดเชียงราย

SmartSync — A Requisition Support System for Inventory Balance in HPH Networks, Mueang Chiang Rai

## เกี่ยวกับโครงการ

ระบบสนับสนุนการคำนวณและคัดกรองยอดเบิกยา NCD สำหรับเครือข่ายโรงพยาบาลส่งเสริมสุขภาพตำบล (รพ.สต.) 29 แห่ง ในอำเภอเมือง จังหวัดเชียงราย ภายใต้การดูแลของกลุ่มงานเภสัชกรรม โรงพยาบาลเชียงรายประชานุเคราะห์ (รพ.แม่ข่าย)

รายละเอียดที่มาของโครงการและขอบเขตปัญหา ดูได้ที่ [01-requirements/01-spec/20260816-001-project-scope-and-problem-background.md](01-requirements/01-spec/20260816-001-project-scope-and-problem-background.md)
